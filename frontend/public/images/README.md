# 📁 Dossier Images

## 🎨 Logo BusinessBuy

**Placez le logo BusinessBuy ici :**

### Fichier requis :
- `logo.png` - Le logo principal de BusinessBuy

### Caractéristiques recommandées :
- **Format** : PNG avec fond transparent
- **Dimensions** : 512x512 px (ou plus haute résolution)
- **Poids** : < 500 KB

### Utilisation dans l'application :

Le logo est utilisé dans :
1. ✅ **Navbar** - Affichage en haut de toutes les pages (hauteur: 50px)
2. ✅ **Footer** - En blanc inversé (hauteur: 80px)
3. ✅ **Page d'accueil** - Hero section (hauteur: 120px)
4. ✅ **Favicon** - Icône de l'onglet du navigateur

---

## 📝 Instructions d'installation

1. Sauvegardez votre logo BusinessBuy sous le nom : **`logo.png`**
2. Placez-le dans ce dossier : `frontend/public/images/`
3. Rafraîchissez votre navigateur (Ctrl+F5)

---

## 🎯 Résultat attendu

Une fois le logo placé, vous verrez :
- Le logo BusinessBuy dans la navbar avec le texte "BusinessBuy"
- Le logo dans le footer en blanc
- Le logo dans la hero section de la page d'accueil
- Le logo comme favicon dans l'onglet du navigateur

---

**Note** : Le logo actuel utilise les couleurs bleu foncé (#1e3a8a) et bleu clair (#3b82f6) pour correspondre au thème de l'application.
